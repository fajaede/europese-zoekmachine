🔧 Integratie in Je Website ? Wat is de "pages" parameter?

De pages parameter vertelt de zoekmachine waar deze specifieke pagina over gaat.

Hoe vul je het in?
1. Ga naar elke pagina van je website
2. Plak het script in de <head>
3. Vul bij "pages:" alleen die 1 pagina in

Voorbeeld voor homepage: 
pages: {
  '/': "Jouw bedrijfsnaam - Korte beschrijving van je homepage met belangrijke keywords."
}
Voorbeeld voor diensten pagina: 
pages: {
  '/diensten': "Beschrijving van je diensten. Noem je belangrijkste services."
}
Herhaal dit voor elke pagina!

Tips: • Gebruik natuurlijke taal
• Houd het kort (1-3 zinnen)
• Gebruik woorden die klanten zoeken
• Vermijd jargon
