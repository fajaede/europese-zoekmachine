🔧 Integratie in Je Website ? Wat is de "pages" parameter?

De pages parameter vertelt de zoekmachine waar deze specifieke pagina over gaat.

Hoe vul je het in?
1. Ga naar elke pagina van je website
2. Plak het script in de <head>
3. Vul bij "pages:" alleen die 1 pagina in

Voorbeeld voor homepage: 
pages: {
  '/': "Jouw bedrijfsnaam - Korte beschrijving van je homepage met belangrijke keywords."
}
Voorbeeld voor diensten pagina: 
pages: {
  '/diensten': "Beschrijving van je diensten. Noem je belangrijkste services."
}
Herhaal dit voor elke pagina!

Tips: • Gebruik natuurlijke taal
• Houd het kort (1-3 zinnen)
• Gebruik woorden die klanten zoeken
• Vermijd jargon

  • Tot 8 trefwoorden waar de pagina over gaat.

Direct na betaling

  • Je pas is meteen actief op je bestaande API-key. Je hoeft niets in je code aan te passen.
  • Je krijgt een bevestigingsmail met het pakket, het bedrag en de einddatum.
  • Bij Usage Statistics hieronder zie je je pakket, tot wanneer het geldt en hoeveel je vandaag hebt gebruikt.
  • Ongebruikte aanvragen schuiven niet door naar de volgende dag. Na de einddatum val je automatisch terug op Free; je key blijft werken.

Waarom 90 dagen?

Google heeft meestal enkele weken tot een paar maanden nodig om nieuwe titels en beschrijvingen op te pikken en het effect te laten zien. Met 90 dagen kun je je pagina's verbeteren én de resultaten volgen, bijvoorbeeld in Google Search Console (vertoningen, klikken en klikratio).

Eerlijk is eerlijk
  • Betere metadata helpt mensen om in Google op jouw resultaat te klikken, maar niemand kan een hogere positie garanderen. Ook wij niet.
  • De API schrijft de metadata. Je zet ze zelf in de HTML van je pagina's, het liefst server-side (zie Integratie hierboven).
  • Google kiest soms zelf een andere titel of beschrijving dan die op je pagina staat.
